# Бюджет семьи — приложение для Android (Python / Kivy)

Аналог вашей таблицы `Расходы_семьи.xlsx`:

- Доход мужа / Доход жены / Общий доход / Расходы семьи / Остаток денег — считаются автоматически.
- Список расходов: дата, сумма, наименование.
- Ввод расхода упрощён под телефон: большая цифровая клавиатура на экране, кнопки
  "Сегодня/Вчера" вместо ручного набора даты, кнопки быстрого выбора категории
  (подставляются самые часто используемые + стандартный набор). Печатать почти не нужно.
- Данные хранятся локально на телефоне (SQLite), работает полностью офлайн.
- Кнопка «Экспорт» сохраняет данные в `.xlsx` в том же формате, что и исходная таблица
  (с формулами, файл открывается в Excel/Google Таблицах).

## Файлы проекта

- `main.py` — интерфейс приложения (экран, кнопки, всплывающие окна).
- `storage.py` — хранение данных (SQLite) и экспорт в xlsx.
- `buildozer.spec` — настройки сборки APK.
- `smoke_test.py` — необязательный скрипт для проверки логики без телефона.

## 1. Проверить на компьютере (перед сборкой APK)

Так можно быстро посмотреть и потыкать интерфейс мышкой, не собирая APK.

```bash
pip install kivy openpyxl
python main.py
```

Откроется обычное окно с тем же интерфейсом, что будет и на телефоне.

## 2. Собрать APK для Android

Сборка Android-приложений из Python делается через **Buildozer** и требует Linux
(на Windows — через WSL2). Сам буilder использует интернет для скачивания Android
SDK/NDK при первой сборке, поэтому соберать нужно на своём компьютере или через
облачный CI (например, GitHub Actions) — из песочницы, где сейчас пишется этот
код, собрать APK нельзя (нет доступа к серверам Google/Android).

### Вариант A — на своём Linux/WSL

```bash
sudo apt update
sudo apt install -y python3-pip build-essential git zip unzip openjdk-17-jdk \
    autoconf libtool pkg-config zlib1g-dev libncurses5-dev libffi-dev

pip install --user buildozer cython

cd family_budget_app
buildozer android debug
```

Готовый файл появится в `bin/budget-1.0-arm64-v8a_armeabi-v7a-debug.apk`.
Первая сборка займёт много времени (скачивается Android SDK/NDK, ~1-2 ГБ).
Скопируйте .apk на телефон и установите (разрешите установку "из неизвестных
источников" в настройках Android).

### Вариант B — через GitHub Actions (не нужен свой Linux)

В проекте уже есть готовый файл `.github/workflows/build.yml`. Просто:

1. Создайте репозиторий на GitHub и залейте туда всю папку `family_budget_app`
   (включая скрытую папку `.github`).
2. Откройте вкладку **Actions** в репозитории — сборка запустится сама после
   пуша в ветку `main`, либо нажмите **Run workflow** там же, чтобы запустить
   вручную.
3. Когда сборка завершится (первая — минут 20-30, дальше быстрее благодаря
   кешу), зайдите в неё и внизу страницы найдите **Artifacts → budget-apk** —
   там будет готовый `.apk`, скачайте и установите на телефон.

## 3. Дальнейшие правки

- Список категорий по умолчанию — переменная `DEFAULT_CATEGORIES` в начале
  `main.py`, можно поменять под свои траты.
- Цвета интерфейса — константы `COLOR_*` там же.
- Экспорт сохраняется в приватную папку приложения
  (`<внутреннее хранилище>/Android/data/org.family.budget/files/export/`);
  если нужно, чтобы файл сразу расшаривался (например, в Telegram/почту),
  это отдельная небольшая доработка через `plyer` — тоже могу добавить.
